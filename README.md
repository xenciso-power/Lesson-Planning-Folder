# Mr. Enciso’s POWER Program – Lesson Planner

Private lesson planning tool for the **POWER Program** at La Viña Middle School (8th Grade After-School).

## Schedule Blocks

| Time Block              | Time          |
|-------------------------|---------------|
| SUPPER                  | 2:32 – 2:50   |
| SEL / CHECK-IN          | 2:52 – 3:00   |
| INTERVENTION            | 3:00 – 3:45   |
| ENRICHMENT              | 3:49 – 4:15   |
| SPARK                   | 4:19 – 5:00   |
| SNACK / DISMISSAL       | 5:00 – 5:15   |

> SPARK and Enrichment are interchangeable based on conditions. Times are subject to change.

## Features

- Individual planning pages for every time block
- C.A.N. Standards Focus section
- Week selector with local saving
- Save, Export (JSON), and Print
- Uses the original XE logo

## How to Use

1. Open `index.html` in any modern browser
2. Enter the week (example: `Aug 4 – Aug 8, 2026`)
3. Click through the time blocks on the left
4. Fill in the lesson details for each day
5. Click **Save** (or press `Ctrl + S` / `Cmd + S`)

All data is stored in your browser. Use the **Export** button if you want a backup file.
